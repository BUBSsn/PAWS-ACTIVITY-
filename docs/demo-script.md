# Demo recording script (about 3 minutes)

Use fictional data. Start with `npm run dev`, open localhost:3000, and show the local demo banner. The identity selector demonstrates workflows, not production authentication.

**0:00-0:20 - Introduction**

"This is our PAWS form-controls activity. We implemented two major forms and two supporting forms using React and Node.js. Each form has eight input controls and two action buttons. The default classroom mode saves records on this computer; a Supabase configuration is included separately."

**0:20-0:55 - Create Event (Ana Cruz, Staff)**

Submit a blank form to show errors and focus moving to the first invalid input. Fill a title, description, today's date, 09:00 start, 12:00 end, and capacity 20. Turn on current vaccination required and create the event. Show the saved event board entry. Explain that qualification flags are saved with the event.

**0:55-1:30 - Volunteer Profile (Maya Santos)**

Select Maya, open My profile, and show the eight data inputs. Show an invalid email or phone message. Fill valid fictional details and vaccination dates, attach a sample document, and save. Show the summary and vaccination status. Reload to demonstrate persistence. If showing expired evidence, explain that saving historical information is allowed while restricted-event eligibility is blocked.

**1:30-2:15 - Remote Work**

Use an unused time period to avoid overlap rejection on repeated demonstrations. Enter an activity, category, assigning staff Ana, today's date, 13:00-15:30, a detailed description, and a sample proof document. Submit and show Pending status with zero credited time. Switch to Ana, open Remote work, download/view the evidence, and approve the submission. Show 2h 30m credited. Explain that volunteers cannot approve their own hours and a second approval is blocked.

**2:15-2:50 - Reports**

Open Reports. Briefly show end-before-start validation, then restore a valid range. Generate a report and point out the record and credited total. Choose Preview + CSV download and generate again. Filter to a volunteer without work to show No records found.

**2:50-3:10 - Accessibility and code**

Use Tab to demonstrate visible focus, show labels and helper text, and narrow the browser to demonstrate mobile layout. Show the actual project directory and repository. Close with the group members' genuine contributions. Record within the required 2-4 minute window.
