The writing-plans skill referenced by brainstorming is not installed; this file provides the implementation plan directly.

Visual direction: bright #00CB00 action accents, #1E1E1E typography, #FAF4EC canvas, white panels. Rounded sans-serif system headings, quiet system body text, tabular numerical data. Persistent left navigation and a contextual right-hand result panel connect each form to its saved outcome. A small paw illustration and shelter-oriented copy give identity without distracting from the forms. Use dark text on bright green for contrast.
